======================================================================
                         MOON LAUNCHER
     Interactive Minecraft CLI Launcher & Configuration Studio
======================================================================

CARA PAKAI:
1. Klik 2x file "Moon Launcher.bat".
2. Di dalam menu Moon Launcher Studio:
   - /play                : Menjalankan Minecraft
   - /setting             : Buka menu setting RAM, Resolusi, dan Akun
   - /setting ram <gb>    : Cepat atur RAM (contoh: /setting ram 10)
   - /setting user <nama> : Cepat ganti nama pemain
   - /version             : Ganti profil modpack
   - /status              : Cek diagnosa sistem, RAM, Java, Discord RPC, & mod
   - /mods                : Lihat daftar mod terpasang
   - /help                : Bantuan perintah
   - /exit                : Keluar launcher

FITUR:
- Ringan, cepat, tanpa iklan/bloatware.
- Terhubung otomatis dengan profil modpack (DeadZone, NightfallCraft, dll).
- Terintegrasi Discord Rich Presence (Discord RPC):
  * Saat di menu: Status menampilkan "In Moon Launcher Studio" & modpack aktif.
  * Saat bermain (/play): Status menampilkan "Playing <Modpack>" dengan detail
    versi Minecraft, loader (Forge/Fabric), jumlah mod aktif, dan timer bermain.
- Mendukung Forge, Fabric, Vanilla, dan NeoForge.
